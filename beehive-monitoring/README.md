# IoT Beehive Monitoring System

An IoT-based hive health monitoring system, developed as part of a university project (ECTE351, AustSTEM, Team 4 — "Wanna-Bees").

Note: This folder contains the components I personally developed as part of a larger group project (team of 5). The full system also includes a sensor node and additional features built by teammates.

## My Contribution
- Power management architecture — duty-cycled sampling, GPS exception handling
- Receiver node design, built on a Raspberry Pi Pico W
- Tile-based web dashboard, including a Hive Health Score algorithm

## Tech Stack
C/C++, Raspberry Pi Pico W, embedded systems
